# Community catalogue

`cards.json` is Perq's canonical public community catalogue. It contains reusable card identity and official page references only.

It must never contain a user's card selection, generated offers, simplified descriptions, rankings, expiry state, card numbers, credentials, or login-only content.

Each card has a stable `id`, ISO country code, issuer, display name, and one or more official sources. Source kinds are `card`, `benefits`, `offers`, `events`, or `rewards`.

Private copies can check the latest version at:

`https://raw.githubusercontent.com/saushank3poch/perq/main/catalogue/cards.json`

For a new card or corrected link, follow [CONTRIBUTING.md](../CONTRIBUTING.md).
